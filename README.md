# 🎬 Netflix Clone — React & TheMovieDB API

Aplicação web desenvolvida em React que recria a interface da Netflix, consumindo dados em tempo real da API do The Movie Database (TMDB).

> 🔗 **Deploy online:** [Link da Vercel virá aqui]

---

## 🚀 Funcionalidades

- **Destaque Dinâmico (Hero Banner):** Exibe um filme ou série original da Netflix selecionado aleatoriamente a cada atualização, com sinopse e botões de ação.
- **Fileiras de Filmes e Séries:** Carrosséis horizontais categorizados (Originais Netflix, Em Alta, Mais Votados, Ação, Comédia, Terror, Romance e Documentários).
- **Player de Trailers:** Ao clicar em qualquer título, abre um modal interativo com sinopse completa, nota da comunidade e o trailer oficial rodando via YouTube.
- **Navegação Inteligente:** Barra superior transparente que se adapta com fundo preto sólido conforme a rolagem da página.
- **Interface Responsiva:** Design otimizado para desktop, tablets e celulares.

---

## 🛠️ Tecnologias Utilizadas

- **[React](https://react.dev/):** Biblioteca para construção da interface de usuário baseada em componentes.
- **[Vite](https://vite.dev/):** Ferramenta de build rápida e moderna.
- **[Axios](https://axios-http.com/):** Cliente HTTP para consumo da API REST do TMDB.
- **[TheMovieDB API](https://www.themoviedb.org/):** Base de dados de filmes, séries, cartazes e trailers.
- **CSS3 Moderno:** Flexbox, animações de transição suave (*transform scale*) e gradientes lineares.
